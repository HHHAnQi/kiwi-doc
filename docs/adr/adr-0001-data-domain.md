# ADR-0001: 数据领域选择 — 中文 Spring Cloud Alibaba 生态技术文档

- Status: Accepted
- Date: 2026-07-27

## Context

项目定位为"企业私有多模态 RAG 智能中台"，需选择一个数据领域（Domain）作为业务叙事和评测基线。约束：

1. **数据合法**：无公司内部文档可用，明确拒绝爬虫，须为公开开源协议。
2. **不降级设计**：数据类型（Type）必须有足够复杂度（表格 / 代码 / 配置 / 图）以验证 parser、VLM caption、Rerank 等模块。
3. **叙事可信**：用户画像清晰，能现场判断答案对错。
4. **可公开演示**：语料可放 GitHub + demo 站点。
5. **中文优先**：避免英文降级。

## Decision

选择「中文开源技术文档（Spring Cloud Alibaba 生态）」作为数据领域。

主语料：Nacos / Sentinel / Dubbo / Seata / RocketMQ / Spring Cloud Alibaba 官方文档。扩展至 CNCF 中文文档与国内开源脚手架文档。

## Alternatives Considered

| 方案 | 数据合法 | 数据类型复杂度 | 中文友好 | 面试共鸣 | 结论 |
|---|---|---|---|---|---|
| 英文 Apache/CNCF 技术文档 | ✅ | ✅ | ❌ 英文为主 | ⚠️ | 否决 |
| 金融年报（SEC EDGAR） | ✅ | ✅ | ✅ | ⚠️ 行业壁垒 | 否决 |
| 医疗指南 | ⚠️ 部分受限 | ⚠️ 纯文本多 | ✅ | ⚠️ 受众窄 | 否决 |
| 法律法规 | ⚠️ 收紧 | ❌ 纯文本 | ✅ | ⚠️ | 否决 |
| **中文 SCA 生态技术文档** | ✅ Apache 2.0 | ✅ 代码/YAML/架构图 | ✅ 中文优先 | ✅ 对齐用户画像 | **采纳** |

## Consequences

+ 用户画像 = Java 后端 / 架构师，演示即拷打。
+ 数据类型丰富（YAML / Java 代码 / Mermaid 图 / 版本差异），不降级任何模块设计。
+ Apache 2.0 协议可商用可发，零版权风险。

- 语料领域偏窄，拓展到非技术领域需重标评测集。
- 中文技术文档翻译可能滞后，需处理中英混排。

缓解：多语言用 BGE-M3 原生支持；版本作为元数据写入 Milvus 过滤。

## Revisit

- 目标岗位转向金融/医疗 → 重新评估。
- SCA 社区出现官方 AI 助手 → 评估项目继续价值。
